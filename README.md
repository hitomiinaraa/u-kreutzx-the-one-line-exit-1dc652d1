# The One-Line Exit

One funny one-line resignation letter for [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1) on make.fun.

`main.ts` writes the entry to `/output/entry.txt`:

> Please accept this as my resignation, effective today: after five years of 'per my last email,' I am finally per my last day.

125 characters, exactly one line, deterministic across runs.
